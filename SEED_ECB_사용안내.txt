SEED-ECB Python 포터블 도구

Python 3.10 이상이면 pip 설치 없이 실행할 수 있습니다.
Windows: 시작_SEED_ECB.bat 더블클릭
화면 실행: python SEED_ECB_portable.py

화면에는 방식 선택, 키 입력, 본문 입력, 결과 표시만 있습니다.

키
기본 형식은 문자열(UTF-8)입니다. 영문·숫자 키는 16자를 입력하세요.
Hex 키는 키 형식을 Hex로 바꾸고 32자리를 입력하세요.
키는 정확히 16바이트여야 합니다. 한글 키는 UTF-8 바이트 수로 계산합니다.

암복호화
암호화 또는 복호화를 고르고 입력창에 본문을 붙여넣은 뒤 실행합니다.
암호문이 Hex 또는 Base64라면 입력 형식을 맞추세요.
결과 형식도 선택할 수 있습니다. 결과는 오른쪽 창에 표시됩니다.
긴 문자열도 처리하지만, 순수 Python이라 매우 큰 입력은 시간이 걸릴 수 있습니다.

방식 설정
다른 시스템에서 만든 암호문을 복호화할 때는 키와 패딩을 맞추세요.
기본 패딩은 PKCS#7입니다. ECB 방식은 IV를 사용하지 않습니다.
패딩 없음은 본문 바이트가 16의 배수일 때 사용하세요.
0x00 채우기는 끝에 있던 실제 0x00과 패딩을 구분할 수 없습니다.

SEED는 128비트(16바이트) 블록 암호이며 키도 16바이트입니다.
알고리즘 기준: RFC 4269
https://www.rfc-editor.org/rfc/rfc4269.html

소스 수정 후 배포 파일을 다시 생성하려면:
python build_seed_portable.py

공식 알고리즘 예제를 확인하려면:
python -S check_seed.py
